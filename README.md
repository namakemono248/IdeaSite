# Idea Tree

ゲームアイディアを階層型ツリーで整理する、シンプルなブラウザアプリです。

## 使い方

- `index.html` をブラウザで開くと使えます。
- 「メインアイディア」で新しいルート項目を追加します。
- 各項目の `+` で子項目を追加します。
- `✎` で名前とメモを編集します。
- `×` で項目と、その配下の項目を削除します。
- `▾ / ▸` で子項目を折りたたみ・展開します。
- フッターからJSONの書き出し・読み込みができます。

## 保存について

データはブラウザの `localStorage` に自動保存されます。同じブラウザ・同じサイトのデータ領域で利用できます。ブラウザのサイトデータを削除すると消える可能性があるため、時々JSONを書き出してバックアップしてください。

## GitHub Pagesで公開

1. GitHubに新しいリポジトリを作成します。
2. `index.html`、`style.css`、`script.js`、`README.md` をリポジトリのルートにアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチの `/(root)` を選んで保存します。
5. 公開URLが表示されたらアクセスします。

※ GitHub Pagesで公開するだけならビルド工程は不要です。
